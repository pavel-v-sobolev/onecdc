# План проекта OneCDC

Назначение проекта, принятые решения и открытые задачи. История изменений — в
[CHANGELOG.md](CHANGELOG.md), результаты аудита 0.2.1 — в
[audit/audit_status_0.2.1.md](audit/audit_status_0.2.1.md), устройство библиотеки — в [DESIGN.md](DESIGN.md).

## Задача

Загружать изменения из 1С через стандартный интерфейс OData в PostgreSQL. Для базового запуска
на стороне 1С достаточно настроить публикацию и план обмена; дополнительный дроссель нужен
для ограничения больших пакетов. Проект поставляется как пакет PyPI и Docker-образ.
Стандартный образ настраивается переменными окружения и не требует пользовательского Python-кода.

## Принятые решения

- Дистрибутив и Python-пакет называются **onecdc**. Имена классов — в PascalCase, без суффикса `1C`.
- Основной класс — **`Replicator`** с методами `run_once()`, `run_forever(interval)` и `full_load()`.
- Конструкторы принимают **отдельные именованные аргументы**. Команда `onecdc` и шаблон
  `config/runner.py` сами читают окружение и явно передают значения конструктору.
- Подключение к БД передаётся готовым **`engine`**. Размером пула управляет приложение;
  расчёт описан в [README_DB.md](README_DB.md#сколько-нужно-соединений-к-бд).
- Целевая СУБД — **PostgreSQL**. Тесты работы с БД используют отдельные схемы PostgreSQL,
  поскольку проверяют в том числе специфичные для неё типы, блокировки и SQL.
- Поддерживается Python **3.10 и новее**, лицензия — **MIT**.

## Состояние

Реализованы репликация изменений, полная выгрузка, обработчики витрин, расписания и упаковка
для PyPI и Docker. Проверки на демобазах УТ и БП и результаты разбора 45 находок аудита 0.2.1
описаны в документах выше; это результаты конкретных проверок, а не гарантия для любой конфигурации.

## Открытые задачи

- **Добавить линтер в CI.** Сейчас матрица Python 3.10–3.14 запускает `pytest`.
- **Рассмотреть общий `requests.Session`** для повторного использования HTTP-соединений с 1С.
- **Уточнить настройку доверия к HTTPS-сертификатам.** Отдельного параметра `verify_ssl` нет.
  Для внутреннего центра сертификации можно передать путь к доверенному набору сертификатов
  через окружение Requests; отключение проверки не является настройкой OneCDC.
