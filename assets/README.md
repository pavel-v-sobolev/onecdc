# Иконки кнопок обработки onecdc

Иконки для командных кнопок формы внешней обработки `onecdc.epf`.

Назначаются кнопке в конфигураторе: свойство **Картинка** → «Очистить» → выбрать
источник **«Из файла»** → указать PNG-файл. Тогда картинка хранится внутри `.epf` и не
зависит от конфигурации, в которой обработка запущена. Ссылки на библиотеку
картинок конфигурации использовать нельзя — они хранятся по внутреннему
идентификатору и могут не разрешаться в другой базе.

## Соответствие кнопок и файлов

| Кнопка на форме | Файл | Смысл иконки |
|---|---|---|
| `Обновить` | `refresh-32.png` | круговая стрелка |
| `ВключитьПланИЕгоОбъктыВODATA` | `odata-32.png` | глобус — публикация в веб-интерфейс OData |
| `ИнициализироватьВыгрузкуВсехОбъектов` | `init-32.png` | молния — стартовая регистрация |
| `ПолнаяВыгрузкаОбъекта` | `upload-object-32.png` | один лист + зелёная стрелка вверх |
| `ПолнаяВыгрузкаВсехОбъектов` | `upload-all-32.png` | стопка листов + зелёная стрелка вверх |
| `ОчиститьИзмененияОбъекта` | `clear-object-32.png` | один лист + красный крест |
| `ПолнаяОчисткаВсехИзменений` | `clear-all-32.png` | стопка листов + красный крест |

Логика набора: цвет отвечает за действие (зелёный — выгрузка, красный — очистка,
синий — чтение/служебное), количество листов — за область (один объект или все).

## Картинка группы-подменю

Для группы команд выгрузки и очистки с видом «Подменю» предусмотрены два варианта:

| Файл | Смысл иконки | Когда использовать |
|---|---|---|
| `menu-32.png` | стопка листов + синий треугольник вниз | повторяет листы на иконках команд и обозначает раскрывающееся меню |
| `service-32.png` | синяя шестерёнка | помогает отличить группу от соседних команд |

Картинка назначается группе так же, как кнопке: **Картинка** → «Из файла».
Если вместо подменю выбран путь «Только во всех действиях» у кнопок — картинка не
нужна: меню «Ещё» рисует платформа.

## Размеры

В обработке используются иконки **32 × 32 px**. Файлы 64 × 64 px предназначены
для документации и редактирования.

Вариант 16 px генератор умеет рисовать отдельно и упрощённо (толще контур, два листа
вместо трёх — иначе на таком размере детали сливаются), но в комплект он не входит:
см. `SIZES` в `make-icons.py`.

## Повторная генерация
